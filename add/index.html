        Help and settings

        Share straight from the YouTube app

        Android: with Tailscale on, open in Chrome, tap ⋮, then Install app (or Add to Home screen → Install). After that, YouTube's Share menu has Add videos (look under More the first time).

        This needs the Pi's Tailscale https address. On the Pi run remote-on once; the address then appears here.

        iPhone: make a Shortcut once (about 5 minutes); then YouTube's Share menu has Send to toy, and the toy gets the video with no more taps.

        1. Open the Shortcuts app, tap +, and name the shortcut Send to toy.
        2. Tap ⓘ (Details) and turn on Show in Share Sheet. Back in the shortcut, in the Receive … from Share Sheet line keep only URLs and Text, and set If there's no input to Get Clipboard.
        3. Add the action Get Contents of URL. URL:
        4. In that action tap Show More: Method POST. Under Headers add X-TStream-Key with the value . Request Body JSON: add a Text field named url and set it to Shortcut Input.
        5. Add Get Dictionary Value: Value for message in Contents of URL.
        6. Add Show Notification with Dictionary Value.
        7. Try it: in YouTube tap Share → More → Send to toy; allow it to connect when asked (Always Allow). Tip: Edit Actions in that menu puts it at the top.

        The Shortcut needs the Tailscale app connected on this phone.

        Tap a grey box to copy it. Videos go to the category last used on this page. The key works like the PIN; tstream new-pin on the Pi cancels every key.
